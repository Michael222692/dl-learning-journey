## 1. 一句话概括

SN2N 是一种用于活细胞超分辨率显微图像去噪的自监督学习方法，目标是在缺少大量干净参考图像的情况下完成模型训练。

## 2. README 中的整体流程

1. 生成自监督训练数据。
2. 训练 SN2N 模型。
3. 使用训练后的模型进行推理和图像去噪。
